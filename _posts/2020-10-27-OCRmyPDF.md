I found this tool very useful so I want to share it here. This post contains only a brief explanation of how to install and use OCRmyPDF, you can see detailed instructions in [OCRmyPDF Documentation](https://ocrmypdf.readthedocs.io/en/latest/index.html)

# Installation on Ubuntu
1. Install using the following command
``sudo apt-get install ocrmypdf``

# Installation on Windows
My suggestion is to install "Ubuntu" from the Windows Store to have access to an Ubuntu terminal from Windows and install from there using the previous instructions. If you do so, the windows hard drive will be mounted on /mnt/c/ (important if you want to convert files stored in the windows filesystem, e.g. on your Desktop)

# Usage
1. Change to the directory containing the file you want to convert

   `cd DIRECTORY`

2. Execute OCRmyPDF with the following command (replace a.pdf and o.pdf with the appropiate names):
    
   `ocrmypdf a.pdf --output-type pdf o.pdf`
