## Suggested learning roadmap
0. Learn ML basics (regression; classification; NNs basics)
1. Learn RL application first
  a. Read Ch1-Ch4 of Sutton's book (do not take too long on small details for the first read)
  b. Watch Silver's RL lectures, Levine's DRL lectures, Abbeel Foundations of RL lectures
  c. Try to implement Q-Learning on simple environment from any book or video (the ones that look like graphs, but gridworld can be an option too). Implementing the methods is very useful for real understanding.
2. Watch RL Theory Course from Szepesvari; Read Badint Algorithms sections suggested; Read 
3. For people with no mathematical background (my case when starting PhD), I suggest reading Axler's MIRA book complementary material; which I think is the most useful since it discusses supremums/infimums/ and other concepts that are used a lot in theory papers.
