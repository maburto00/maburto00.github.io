These tools are useful for cases when you cannot select and copy the text directly (e.g. mangas in Kindle, slides in Zoom/Youtube, etc).

## Android
- [Kaku - Floating Japanese Dictionary (OCR)](https://play.google.com/store/apps/details?id=ca.fuwafuwa.kaku&hl=en&gl=US)

## Windows
- [★Capture2text](http://capture2text.sourceforge.net/)
  - This is a very powerful tool. Please read the manual to really take out all its potential.

## Mac
- [capture2text OCR Mac Alternative with Automator](https://www.youtube.com/watch?v=gf1c1RXzphE)
   - This method is slower than the others, but it was the only alternative I found for Mac. This method will only capture the text, so you have to copy the text to another tool for translation.
