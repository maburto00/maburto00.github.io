These tools have been very useful while learning japaneseI put here the software I have use for learning japanese.

# Iphone
- [Google Translate](https://play.google.com/store/apps/details?id=com.google.android.apps.translate&hl=en&gl=US)
  - Useful to Translate Japanese to English or English to Japanese. Specially useful is the camera tool to translate live or to "scan" and translate by selecting the text. Another useful tool is the writing tool, which permits to write kanji directly, and even if not written too accurately the system is able to recognize it and offers some suggestions too.
- [Japanese](https://apps.apple.com/jp/app/japanese/id290664053)
  - I am not joking, the app is called "Japanese". It is a very useful dictionary for iPhone, specially the function where you can draw/sketch a Kanji in the app and it will show you suggestions of what kanji it is. This is very useful for cases when you do not know the pronunciation of but Kanji but you want to search for it.


# Android
- [Google Translate](https://play.google.com/store/apps/details?id=com.google.android.apps.translate&hl=en&gl=US)
  - Useful to Translate Japanese to English or English to Japanese. Specially useful is the camera tool to translate live or to "scan" and translate by selecting the text. Another useful tool is the writing tool, which permits to write kanji directly, and even if not written too accurately the system is able to recognize it and offers some suggestions too.
- [Takoboto](https://play.google.com/store/apps/details?id=jp.takoboto&hl=en&gl=US) (Japanese-English Dictionary)
  - Japanese English Dictionary that searches for the words while you are typing, which makes it very convenient to search quicly for words. It permits to search both in English and in Japanese (using romaji, kana or kanji).
- [Kaku - Floating Japanese Dictionary (OCR)](https://play.google.com/store/apps/details?id=ca.fuwafuwa.kaku&hl=en_US&gl=US)
  - OCR (Optical Character Recognition) system to capture and translate text in Japanese. Specially useful for manga in Kindle or PDF where you cannot select the text, or for slides in Japanese shown on Zoom or Youtube videos. See also Windows->Capture2Text for a similar tool for Windows.

# Chrome Extensions
- [Yomitan](https://chromewebstore.google.com/detail/yomitan/likgccmbimhjbgkjambclfkhldnlhbnn) 
  - By holding Shift key and positioning the cursor over a work you can see the furigana, the meaning in English and the meaning of individual Kanji. Extremely useful.
- [Language Reactor](https://www.languagereactor.com/)
  - Adds functionality to the subtitles on Netflix and Youtube so you can put the mouse over the words and see the translation immediately.

# Windows
- [Capture2Text](https://sourceforge.net/projects/capture2text/)
  - I really recommmend reading the [documentation](http://capture2text.sourceforge.net/) completely (it should take about 30minutes) to be able to use this app effectively, since it relies on the use of hotkeys. This is an OCR app so you can capture text from images, but it also has the option to translate directly and even pronounce with text-to-speech.
- [Anki](https://apps.ankiweb.net/)
  - I recommend to use this in moderation, since learning must be fun and Anki can drag the fun out of it very quickly. However, it is a good alternative for physical flash cards, and you can download Shared Decks for classic resources (e.g. Minna No Nihongo, JLPT preparation, Soumatome books, etc). I was never able to use it consistently in the way many people recommend in YouTube, but I used more casually.
