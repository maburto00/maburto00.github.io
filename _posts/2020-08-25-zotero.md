Zotero is a free and open-source reference management software. A reference management software help researchers and students to save, organize and cite research articles in an easier way. Mendeley (free but not open-source) and EndNote (paid and not open-source) are other examples of this kind of software. 

I decided to use Zotero over the other alternatives because it is free permits the edition of PDF files with an external PDF Editor (I use FoxitReader to highlight and make annotations) and the PDF Files can be stored in Google Drive (so less restriction on the limit of papers to store). Mendeley permits annotations in their embeded editor, but the annotations are not saved in the source PDF file, so they can only be visualized throught the program.  Having said that, I have to say Mendeley is way easier to setup and use, so please take into account when deciding which one to use. EndNote seems to be a good alternative too, but I haven't tried it yet so I cannot comment on it.

Next I give just some pointers to resources that I found helpful to install, setup and use Zotero. I recommend specially to refer to [1], which is a great resource. It takes some time to setup, but once setup it is very easy to use.

# Installation
Refer to [1] for detailed instructions for installation on Mac and Windows, and to [2] for installation on Ubuntu.

1. Create a Folder in the root folder of Google Drive called Zotero
2. Download Zotero from https://www.zotero.org/download/
3. Install Zotero (choose "Standard" and leave the default installation directory unchanged)
4. Download Zotfile from http://zotfile.com/
5. Install Zotfile.
  6. Launch Zotero
  7. Go to Tools-> Add-ons -> "Gear Icon" -> Install Add-on from file
  8. Select the downloaded file from step 3 and click install now and then click restart zotero when asked
9. Setup Zotero
  10. Go to Edit -> Preferences -> Sync and login with your Zotero account (or create one)
  11. In the same Preferences menu go to Advanced -> Files and Folders and setup Base Directory to the folder named "Zotero" in Google Drive
  12. Go to Tools -> Zotfile Preferences and set Source Folder for Attaching new files to your Downloads directory
  13. In the same Zotfile Prefrences menu set the Location of Files-> Custom directory to the folder named "Zotero" in Google Drive
  14. In the Zotero main windows click on the sync icon (green circular arrow at the top right) to Sync with your account
