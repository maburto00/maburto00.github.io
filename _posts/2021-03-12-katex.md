# Troubleshooting on Windows
I had problems running Katex locally on Windows. Apparently the problem is on the JavaScript Runtime. After trying many things, I actually solved the problem by installing [Node.js](https://nodejs.org/en/) as suggested [here](https://stackoverflow.com/questions/12520456/execjsruntimeerror-on-windows-trying-to-follow-rubytutorial), [here](https://stackoverflow.com/questions/7092107/rails-could-not-find-a-javascript-runtime) and [here](https://github.com/railsgirls/railsgirls.github.io/issues/133). 
```sudo apt-get install nodejs```
